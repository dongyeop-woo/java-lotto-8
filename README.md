# java-lotto-precourse

## 기능 목록

### 입력 기능
- [x] 로또 구입 금액 입력 (1,000원 단위 검증)
- [x] 당첨 번호 입력 (쉼표로 구분된 6개 번호, 1-45 범위 검증)
- [x] 보너스 번호 입력 (1-45 범위 검증, 당첨 번호와 중복 검증)

### 입력 검증 기능
- [x] 구입 금액이 1,000원 단위인지 검증
- [x] 로또 번호 개수가 6개인지 검증
- [x] 로또 번호가 1-45 범위인지 검증
- [x] 로또 번호에 중복이 없는지 검증
- [x] 보너스 번호가 당첨 번호와 중복되는지 검증

### 로또 발행 기능
- [x] 구입 금액에 따른 로또 개수 계산
- [x] 로또 번호 랜덤 생성 (1-45 범위, 중복 없음)
- [x] 로또 번호 오름차순 정렬

### 당첨 판별 기능
- [x] 로또 번호와 당첨 번호 비교
- [x] 일치하는 번호 개수 계산
- [x] 보너스 번호 일치 여부 확인
- [x] 당첨 등급 판별 (1-5등)

### 통계 및 수익률 계산 기능
- [x] 당첨 통계 집계
- [x] 총 당첨금 계산
- [x] 수익률 계산 및 소수점 둘째 자리 반올림

### 출력 기능
- [x] 발행한 로또 수량 및 번호 출력
- [x] 당첨 통계 출력
- [x] 수익률 출력
- [x] 에러 메시지 출력

### 예외 처리
- [x] 잘못된 입력 시 IllegalArgumentException 발생
- [x] "[ERROR]"로 시작하는 에러 메시지 출력
- [x] 예외 발생 시 해당 부분부터 다시 입력 받기
